# 🚀 Token BDB - Interfaz Web

Una interfaz web moderna para interactuar con el token BDB (Buen Dia Builders) en la blockchain de Stellar.

## ✨ Características

- 🎨 **Diseño moderno** con fondo oscuro y efectos visuales
- 🔗 **Conexión con Freighter** wallet
- 💰 **Visualización de balance** del token
- 📊 **Información del token** en tiempo real
- 🎮 **Modo demo** para pruebas

## 🚀 Desplegar tu aplicación

### Opción 1: Netlify Drop (Más fácil)

1. Ve a [netlify.com/drop](https://netlify.com/drop)
2. Arrastra la carpeta `dist/` completa
3. ¡Tu aplicación estará online en segundos!

### Opción 2: Vercel

1. Instala Vercel CLI: `npm install -g vercel`
2. Haz login: `vercel login`
3. Despliega: `vercel --prod`

### Opción 3: GitHub Pages

1. Sube la carpeta `dist/` a un repositorio de GitHub
2. Ve a Settings > Pages
3. Selecciona "Deploy from a branch" y elige `main`
4. Tu app estará en `https://tuusuario.github.io/turepo`
